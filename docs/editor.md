# エディター

エディターの画面構成と、Asset Browser、Scene View、Game View、Consoleの使い方を説明します。

[← ドキュメント一覧へ戻る](index.md)

## 基本画面

左側がHierarchy、右側がInspectorです。
HierarchyからGameObjectを選択すると、次の項目を編集できます。

- 名前とEnabled
- Position / Rotation / Scale
- Cameraの画角
- MeshRendererの色
- SpriteRendererのサイズと色
- Tilemapのセルサイズ、Atlas分割、色、タイルシート
- Rotatorの回転速度

上部にはメニューバーと再生ツールバーがあります。

- 「ファイル」: 新規、開く、保存、名前を付けて保存、再読込、終了
- 「編集」: Undo／Redo、切り取り、コピー、貼り付け、複製

シーンに保存していない変更がある状態でエディターを閉じようとすると、「保存して閉じる／保存せずに閉じる／キャンセル」の確認が表示されます。
Play中に閉じる場合はPlay開始前の編集状態が保存対象になります。

### 複数選択とHierarchyの検索

- **Ctrl+クリック**で選択を追加・解除できます（Hierarchy／Scene View
  どちらでも）。
  選択中の数はHierarchy上部に表示されます。
- 複数選択したまま、**削除（Delete）・複製（Ctrl+D）**、そして
  **ギズモでの移動・回転・拡縮**がまとめて行えます。
  ギズモは主選択（明るい水色の枠）を基準に、同じ変化量を他へも適用します。
- Hierarchy上部の検索ボックスに名前を入れると、一致するGameObjectだけを
  平らに一覧表示します（大文字小文字は区別しません）。

### アセットをドラッグ＆ドロップで割り当てる

Asset BrowserのファイルをHierarchyのGameObjectへドロップすると、種類に応じたコンポーネントへ自動で割り当てられます（必要なコンポーネントは自動で追加されます）。

| ドロップするもの | 起きること |
|---|---|
| モデル（glTF/GLB/FBX等） | Model Rendererを追加して表示 |
| 画像 | Tilemapならタイルシート、ボタンならボタン画像、パーティクルなら粒子画像、3D描画ならアルベド、それ以外はSprite Rendererを追加 |
| `.material.json` | Mesh/Model RendererへMaterialを設定 |
| `.hlsl` | 対応するRendererへカスタムShaderを設定 |
| 音声（WAV/OGG） | Audio Sourceを追加して設定 |
| `.animation.json` | Transformアニメーターを追加して設定 |
| `.animator.json` | モデルがあればモデル側、無ければTransform側のControllerへ設定 |
| C++ Script | Game Moduleをビルドしてコンポーネントとしてアタッチ |

Hierarchyの**空白（シーンルート）へドロップ**すると、ファイル名のGameObjectを新規作成して同じルールで割り当てます。
画像をドロップするだけでスプライトが1つできあがります。

**Scene Viewへ直接ドロップすると、落とした場所へ配置されます。**既存のオブジェクトの上へ落とせばその手前、何も無い場所ならグリッド平面（3DはXZ、2DはXY）との交点に置かれます。
Prefabをドロップすればその位置へインスタンスを配置できるので、レベル作りが早くなります。
- 「ファイル」: シーン操作と「プロジェクト設定とビルド...」。設定画面の「ビルドプロファイル」からWindows／Webの書き出しへ進む
- 「GameObject」: 空オブジェクト、2D／3Dオブジェクト、ライト、オーディオ、カメラ、UIの作成と、選択オブジェクトの削除
- 「コンポーネント」: 選択中のGameObjectへ追加するコンポーネントを検索
- 「アセット」: 現在のフォルダーへの新規作成、外部ファイルのインポート、選択項目／全アセットの再インポート、一覧更新、Explorer表示
- 「ウィンドウ」: 各パネル（コンソール／パフォーマンス／セーブデータ／アセット／タイルパレット）の表示、レイアウトの即時保存、標準配置へのリセット
- 「拡張機能」: パッケージを探す、インストール先フォルダーを開く
- 「ヘルプ」: オンライン／ローカルドキュメント、Console、エディターログ、「ヘルプとサポート」画面

標準レイアウトでは、中央下にアセットとコンソールをタブ表示します。パフォーマンス、セーブデータ、タイルパレットは初期状態では閉じておき、必要なときだけ「ウィンドウ」メニューから開けます。
- 再生／停止ボタンはツールバー中央に配置

### プロジェクト専用メニュー

プロジェクトの`.lamapon/editor-menu.json`へ項目を定義すると、そのプロジェクトを
開いている間だけメニューバーへ制作ツールを追加できます。`path`を`/`で区切ると、
最大8階層までネストできます。この設定と起動対象はエディター専用で、
ゲームのエクスポートには含まれません。

```json
{
  "format": "LamaPonEditorMenu",
  "version": 1,
  "items": [
    {
      "path": "ツール/アセットを検査",
      "command": "LamaPonCli.exe",
      "arguments": [
        "validate",
        "--project",
        "."
      ],
      "workingDirectory": ".",
      "enabledWhilePlaying": false
    }
  ]
}
```

`command`には実行ファイルの絶対パス、プロジェクトからの相対パス、または
`PATH`に登録された名前を指定します。`LamaPonCli.exe`が`PATH`にない環境では、
インストール先の絶対パスを指定してください。

外部コマンドの代わりに、LamaPon内へドッキングする制作パネルも指定できます。
BGMのループ範囲を調整する`bgm-loop`の例は次のとおりです。

```json
{
  "path": "サウンド/BGMループ",
  "panel": {
    "type": "bgm-loop",
    "title": "BGMループエディター",
    "data": "config/bgm-loop.json",
    "workingDirectory": "."
  }
}
```

- `path`: 表示名。`/`区切りで1～8階層、同じ先頭名の項目はまとめられます
- `command`: 実行ファイル名、またはプロジェクトルートからの相対パス
- `arguments`: 省略可能な文字列配列。各引数はWindows向けに個別にクォートされます
- `workingDirectory`: 省略時はプロジェクトルート。相対パスも同ルート基準です
- `enabledWhilePlaying`: 省略時は`false`。`true`ならPlay中もその項目を実行できます
- `panel.type`: 組み込みパネルの種類。`bgm-loop`はBGMのループ範囲を編集します
- `panel.data`: パネルが読むプロジェクト相対のJSON
- `panel.saveCommand` / `panel.saveArguments`: 省略可能。パネルがJSONを保存した後に追加の生成処理を実行します

#### BGMループエディター（`bgm-loop`）

長いBGMの**ループ範囲**と**曲の途中から鳴らす位置**を、波形を見ながら決めるパネルです。
`panel.data`のJSONは`tracks`配列を持ち、各要素に次のキーを置きます。

| キー | 意味 |
|---|---|
| `name` | 曲名（一覧に出ます） |
| `asset` | 音源のプロジェクト相対パス |
| `intro_start_frame` / `intro_start_seconds` | 鳴らし始める位置（長いイントロを飛ばす） |
| `loop_start_frame` / `loop_end_frame` | ループ範囲（サンプルフレーム） |
| `loop_crossfade_frames` | 継ぎ目を重ねる長さ（0で重ねない） |
| `preview_start_frame` / `preview_start_seconds` | 曲の途中から鳴らす位置 |
| `preview_end_frame` / `preview_end_seconds` | そこまで鳴らして頭へ戻る位置 |
| `groups` | 自動選曲グループのid一覧（任意） |
| `gain_db` | 音量補正（dB。任意。スライダーで動かせます） |

波形は音源全体をデコードして作るので、曲を選び直したときに一瞬止まります。

- **左クリック**: その位置から試聴します。ループ範囲は編集中の値がそのまま入るので、
  **保存しなくても継ぎ目を耳で確かめられます**
- **右クリック**: その位置を「イントロ開始」「LOOP IN」「LOOP OUT」「試聴開始」「試聴終了」に設定します
- 「イントロ開始」より前は、通常再生で使わない範囲として波形を暗く表示します。
  「▶ イントロから」はイントロ開始からLOOP OUTまで再生した後、ループへ入ります
- 「▶ 試聴範囲」は、指定した試聴範囲だけを繰り返します
- 「▶ 継ぎ目を聞く」はLOOP OUTの3秒手前から鳴らします。折り返しがそのまま来るので、
  段差やブツ切れをその場で聞けます
- 右端のボタンは**鳴っていれば「■ 停止」、止まっていれば「▶ 再生」**に変わります。
  停止しても音源は開いたままなので、再生し直しても読み込みで待たされません
  （「▶ 再生」は直前に鳴らした位置から。まだ一度も鳴らしていなければ試聴範囲）
- 再生中は白い縦線が再生ヘッド、下の棒がエンジンの帯域レベルメーターです
- `gain_db`があると「音量補正」スライダーが出ます。音源を書き換えずに
  曲ごとの音量差をならすためのもので、**鳴らしながら動かせます**
- JSONの直下に`groups`（`id`と`name`の一覧）があると、「自動選曲グループ」の
  チェックボックスが表示されます。曲ごとに`groups`へidを指定し、
  自動選曲の候補をグループ分けできます
- 「保存」で`panel.data`のJSONを書き戻し、`panel.saveCommand`があれば続けて実行します
  （ゲーム側のコードや表へ反映する処理をここへ置きます）

Play中はパネルを休止し、試聴も止めます。

ファイルの追加・変更・削除は、エディターを再起動しなくても数秒以内に反映されます。
誤操作を避けるため、組み込みメニューと同名の先頭項目は追加できません。

Hierarchy、Asset Browser、Viewport、Inspector、Performanceはドッキングウィンドウです。
タイトルのタブを押したままドラッグすると、青いガイドへドロップして左右／上下へ分割したり、別パネルとタブ結合したり、浮動ウィンドウとして切り離したりできます。
パネル間の境界や浮動ウィンドウの端をドラッグするとサイズを変更できます。
変更した構成は自動保存され、次回起動時に復元されます。

「ファイル > シーンを開く...」では、Windowsのファイル選択ダイアログから`.scene.json`を直接開けます。
Play中に発生したランタイム変更は、Stop時にPlay開始前の編集状態へ戻ります。

HierarchyでGameObjectをダブルクリックすると、そのオブジェクトだけを選択してScene Viewのカメラがフォーカスします（Fキーと同じ動作）。
`Scene Root`の行は対象外です。

Hierarchyの空白または`Scene Root`を右クリックするとルートを、GameObjectを右クリックすると子を作成できます。
GameObjectを別のGameObjectへドラッグすると子になり、`Scene Root`へドロップするとルートへ戻ります。親子関係の変更はHierarchyの描画後に適用されるため、既存のGameObject同士でも安全に移動できます。自分自身や自分の子孫を親にする操作はできません。
切り取り、コピー、貼り付け、複製、Prefab保存、削除もGameObjectの右クリックメニューへまとまっています。

各メニュー操作は次のショートカットでも使用できます。

- Undo: Ctrl+Z
- Redo: Ctrl+YまたはCtrl+Shift+Z
- Copy: Ctrl+C
- Cut: Ctrl+X
- Paste: Ctrl+V
- Duplicate: Ctrl+D
- New Scene: Ctrl+N
- Open Scene: Ctrl+O
- Save: Ctrl+S
- Save As: Ctrl+Shift+S
- Reload Scene: Ctrl+R
- Refresh Assets: F5
- Delete GameObject: Delete

## Asset Browser

左下のAsset Browserには`assets`フォルダー内のファイルが表示されます。

- 検索欄でファイルを絞り込み
- パンくず、または「表示方法」で有効にしたフォルダーツリーから階層を移動
- 通常時は選択フォルダー直下のファイルと子フォルダーを表示
- 検索時はすべてのフォルダーを横断して相対パスを検索
- 「表示方法」で一覧／グリッドを切り替え、フォルダーツリーの表示も設定
- 画像はサムネイルとして表示
- 「更新」またはF5でファイルを走査し、GUID・依存関係を更新
- 上部の「アセット > 作成」、またはフォルダー／ファイル一覧の空白の右クリックから、現在位置へフォルダー、シーン、Material、データアセット、Shader、C++ Scriptを作成
- 「アセット > 新しいアセットをインポート...」から複数ファイルを現在位置へ取り込み、同名ファイルは自動改名
- 「アセット > 選択項目を再インポート」で対象キャッシュと利用中Componentを更新し、「すべてのアセットを再インポート」で全キャッシュと全参照を読み直す
- フォルダーを右クリックして、名前とアセット参照の更新または空フォルダーの削除
- ファイルを右クリックして、拡張子を維持した改名または参照確認後の完全削除
- ファイルの右クリックメニューから、そのアセットだけを再インポート
- ファイルをフォルダーツリー、パンくず、フォルダーアイコンへドラッグして移動
- **フォルダーを左ボタンで少し引きずってドラッグし、別のフォルダーやフォルダーツリーの`assets`へ落とすと、中身ごと移動**（自分自身や自分の中へは落とせません。
  同名のフォルダーがある場合は中止します）
- `.scene.json`をダブルクリックしてシーンを開く
- `.cpp`／`.hlsl`をダブルクリックして外部スクリプトエディターで開く
  （プロジェクト設定の「スクリプト」で選択。
  未設定ならWindowsの関連付け）
- `.fbx`を単クリックしてInspectorでインポートスケールを編集
- 画像を右クリックして、選択中の対応Rendererへ割り当て
- 画像をSpriteRendererまたはTilemapのTexture欄へドラッグ＆ドロップ
- Clear Textureで白テクスチャへ戻す

安全のため、`assets`ルート自体、シンボリックリンク、ファイルや子フォルダーを含むフォルダーは削除できません。
フォルダー名の変更**と移動**の時は、Asset Databaseが保存済みのScene、Prefab、Material、Animator ControllerなどのJSON参照も自動更新し、開いているシーンの参照とプロジェクト設定の起動シーンも追従します。

ファイルの移動・改名では対応する`.meta`も一緒に移動してGUIDを維持します。
移動後に画像やモデルを再読込し、CMOなどの依存テクスチャを含めて参照が壊れないか検査します。
再読込に失敗した場合はファイル操作を自動的に取り消します。

ファイル削除時は現在のシーンとAsset Databaseの被依存グラフを走査し、全JSONアセットからの参照を確認ダイアログへ表示します。
参照中のファイルは警告への同意が必要です。
現在のシーンにある直接参照は削除時に自動解除しますが、別のシーンファイルは意図しない編集を避けるため変更しません。
現在開いているシーン自体は削除できません。

削除対象は一度同じフォルダーへ退避され、残りのモデルを再読込してCMOなどの依存テクスチャが壊れないことを確認してから完全削除されます。
依存確認に失敗した場合は元の場所へ戻します。

ファイルを右クリックすると、種類に応じたシーン／Prefab操作、Rendererへの割り当て、再インポート、名前変更、削除、アセット情報、パスのコピー、Explorer表示を選択できます。
フォルダー、パンくず、ファイル一覧の空白を右クリックすると、現在位置での新規作成、名前変更、空フォルダー削除、Explorer表示を選択できます。
上部には検索、更新、一覧／グリッドとフォルダーツリーを選ぶ「表示方法」を配置しています。

### Asset Databaseと.meta

初回起動またはF5更新時に、`assets`内の各ファイルへ同名の`.meta`を生成します。
`.meta`には32桁の一意GUIDとImporter種別が保存されます。

```json
{
  "format": "LamaPonAssetMeta",
  "version": 1,
  "guid": "6b85ceddb749e9ff65f868d8de597ac1",
  "importer": "Texture"
}
```

Scene／Prefabのアセット参照には従来の読みやすい相対パスとGUIDを併記します。
読み込み時はGUIDを優先するため、Explorerでアセットと`.meta`を一緒に移動した場合も新しいパスを復元できます。
GUIDがない旧Scene／Prefabは従来のパスで読み込まれ、次回保存時に自動移行します。

Asset Browserでファイルを右クリックし「アセット情報」を開くと、GUID、Importer、依存数、被依存数を確認し、GUIDをコピーできます。
同じGUIDを持つ`.meta`が複数見つかった場合は、誤った参照を防ぐためImportを停止してエラーにします。

`.meta`にはImporterごとの設定も保存されます。
現在はFBXの`importScale`（次項）が対象です。

### Model Asset Inspector（FBXのインポートスケール）

Asset Browserで`.fbx`を選ぶと、Inspectorが「Model Asset (FBX)」表示に切り替わり、インポート時のスケールを補正できます。
FBXはファイル側の単位設定が実際のモデルサイズと食い違っていることがあり、メートル単位で作られたモデルがセンチメートルとして書き出されて実寸の1/100で読み込まれる、といったケースに対応するための設定です。

- 「スケール」で倍率を入力（0.0001〜10000）
- 「100倍」ボタンでcm→mの取り違えをまとめて補正
- 「既定(1.0)」ボタンで等倍へ戻す
- 「保存」で`.meta`へ書き込み、そのモデルを使用中のModelRendererを再読込
- 「変更を戻す」で保存前の値へ戻す

保存すると`.meta`へ`importScale`が追加されます。

```json
{
  "format": "LamaPonAssetMeta",
  "version": 1,
  "guid": "6b85ceddb749e9ff65f868d8de597ac1",
  "importer": "Model",
  "importScale": 100.0
}
```

スケールはインポート時にモデルのルートノードへ適用され、子ノードには通常の階層変換で伝播します。
ボーンやアニメーションを持つモデルにも適用されます。
この設定はFBXだけが対象で、glTF/GLBやCMOなど他の形式では表示されません。

## Scene ViewとGame View

中央ViewportはSceneタブとGameタブに分かれています。
Scene View左上の`2D`／`3D`ボタンは、プロジェクトのテンプレートに関係なく正面のXY平面と自由な3D視点を切り替えます。
3Dへ戻すと切り替え前のカメラ位置へ復帰します。

- Scene: エディター専用カメラでシーンを編集
- Game: Main Cameraから見た実際のゲーム画面

Game View左上の「解像度」から、パネルに合わせる「自由」と「固定解像度」（1920x1080や縦スマホなどのプリセット付き）を切り替えられます。

固定解像度では、パネルが小さくても指定した画素数で描画してから縮小表示します。
解像度を上げるほどGPU負荷が増えるため、画質とフレームレートを確認しながら選んでください。
Scene ViewとGame Viewは、同じ解像度なら同じ描画経路を使います。

同じポップアップの**描画スケール**（100%／75%／50%）を下げると、アスペクトと割合ベースのUIレイアウトはそのままに画素数だけ減らせます。
「自由」を選んだ場合も、パネルに対する描画解像度の割合として適用されます。
50%では縦横が半分になり、描画する画素数は約4分の1です。
ピクセル指定UIの原寸確認をするときだけ100%へ戻してください。

ポップアップの一番下に**実際の描画解像度**が出ます。
FPSが落ちたときはまずこの数字を見てください。
パネルと同程度の解像度なら、ライトの数、影、ポストエフェクトなどの負荷も確認してください。

Scene Viewのカメラ操作:

- 右マウスドラッグ: 視点回転
- 右マウスを押しながらWASD: 前後左右移動
- 右マウスを押しながらQ/E: 上下移動
- マウスホイール: 注視点へズーム
- Shift: 高速移動
- Fまたは「選択へ」: 選択オブジェクトへフォーカス
  （HierarchyでGameObjectをダブルクリックしても同じ動作になります）

プロジェクト設定の「ビューポート設定」から「オービット操作」を選ぶと、注視点を中心にした操作へ切り替えられます。
Alt+左ドラッグで回転、中ドラッグでパン、Alt+右ドラッグでズーム、右ドラッグでフライ操作です。
回転・パン・ズームの感度とY軸反転もプロジェクト単位で設定できます。

シーン表示の左上に重ねてある「設定」から、次を変更できます。

- 通常の移動速度
- Shiftを押したときの高速倍率
- 右ドラッグの回転感度
- マウスホイールのズーム感度
- グリッド／ビューキューブの表示とグリッド間隔
- 当たり判定を表示（Collider・NavMesh・Sprite Mask・Light 2Dの範囲）
- ライトのギズモを表示（Point Lightの範囲、Directional Lightの向き、Spot Lightの円錐）
- カメラのギズモを表示（Cameraコンポーネントの視錐台）
- 全設定を既定値へリセット

デバッグ線は種類ごとに切り替えます。
ライティングを詰めているときはライトのギズモだけ残す、といった使い方ができます。
3つとも既定でオンです。

同じポップアップからエディター設定の即時保存と全設定のリセットを行えます。
通常終了時にも自動保存され、次回起動時に復元されます。

常時表示のツールバーは設けず、設定ポップアップ内でカメラ操作・投影方式・グリッド・ギズモ・スナップを名前付きプリセットとしてまとめて管理できます。

- 「標準」: 一般的な編集設定
- 「レベルデザイン」: 広いグリッド、高速カメラ、0.5単位スナップ
- 「精密配置」: 0.25グリッド、低速カメラ、0.1単位スナップ
- コンボで選択すると即時適用
- 現在値から新規保存、選択プリセットへの上書き、削除

プリセット適用時もScene Cameraの現在位置・向きとAsset Browserの表示先は維持されるため、作業中の場所を失わず編集スタイルだけを切り替えられます。

設定ファイル:

```text
.lamapon/editor-settings.json
.lamapon/imgui-layout.ini
```

保存される項目:

- Scene Cameraの位置、向き、投影方式、速度、感度
- グリッドの表示、間隔、範囲
- ギズモ操作、ローカル座標、各スナップ値
- Asset Browserの一覧／グリッド表示と現在のフォルダー
- 名前付きプリセットと最後に選択したプリセット
- パネルのドッキング先、タブ構成、分割比率、浮動位置とサイズ

`.lamapon`はユーザー固有の編集状態としてGit管理対象外です。

Scene View右上のView Cubeはドラッグで視点を回転できます。
立方体の面をクリックすると、正面、背面、左右、上面、下面へ視点が揃います。

「正投影」を有効にすると、遠近感のない正投影表示へ切り替わります。
正投影時は「表示サイズ」またはマウスホイールでズームを調整できます。
正投影中の操作はW/Sが画面上下、A/Dが画面左右、Q/Eが奥行き移動になります。
グリッド、View Cube、クリック選択、Transformギズモはどちらの投影方式でも使用できます。

GameObjectを選択するとTransformギズモが表示されます。

3DオブジェクトはScene View上で左クリックして選択できます。
3D Colliderがある場合はColliderを選択領域に使い、プリミティブには描画形状由来のAABB、モデルには現在単位AABBを使います。
選択中の領域は水色の枠で表示されます。

- W: 移動
- E: 回転
- R: 拡縮
- Local: ローカル座標とワールド座標の切り替え

シーン表示の「設定」でXZグリッドの表示、セル間隔、表示範囲を変更できます。
スナップを有効にすると、現在のギズモ操作に応じて次の単位が使われます。

- 移動: ワールド単位
- 回転: 度
- 拡縮: スケール量

スナップを無効にしている場合でも、ギズモ操作中にCtrlキーを押すと一時的にスナップが有効になります。

## 日本語対応

エディターは次の順番でWindowsの日本語フォントを自動検出します。

1. Yu Gothic
2. Meiryo
3. MS Gothic

ソースコード、ImGui入力、JSON、アセットパスはUTF-8で統一されています。
日本語のGameObject名、シーン名、画像名、モデル名を使用できます。

## Consoleとログ

共通`Logger`は最大4096件をメモリへ保持し、時刻、Info／Warning／Error、メッセージ、ソースファイルと行番号、任意のGameObject IDを記録します。
エディター下部の「コンソール」では次を利用できます。

- レベル別件数と表示フィルター
- メッセージ／ソースファイル検索
- 表示の一時停止と自動スクロール
- 右クリックからメッセージまたは行全体をコピー
- GameObject ID付きログのダブルクリック選択
- メモリログのクリア

エディター操作のステータス、エラー、Game Moduleの読込、Scene Managerの要求・成功・ロールバック失敗は自動記録されます。
実行ファイルと同じフォルダーの`LamaPon.log`へもUTF-8で逐次保存されるため、エクスポートしたゲームの調査にも利用できます。

「ヘルプ」→「ヘルプとサポート...」には、オンラインマニュアル、同梱されたローカルドキュメント、Console、ログファイル／フォルダーへの入口をまとめています。
「サポート情報をコピー」はエンジンバージョン、Revision、ビルド構成、プロジェクト、シーン、ログの場所をクリップボードへまとめます。不具合報告時に`LamaPon.log`と一緒に添付してください。
