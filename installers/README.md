# Windowsインストーラー

[LamaPon 0.1.0 Setup.exeをダウンロード](LamaPon-0.1.0-windows-x64-Setup.exe?raw=1)

Windows 10/11向けの配布版です。サイズは10,411,103バイト（約10MB）。Engine、Hub、ランタイムDLL、Game Module SDK、3つの起動ショートカットをまとめて導入します。完了画面からC++自動ビルド環境の確認・セットアップも実行できます。

GitHubでは上のリンク、またはEXEのページの「Download raw file」から取得してください。リポジトリを取得済みなら、このフォルダーのEXEを直接実行できます。

インストーラーは日本語のみです。使用許諾画面にはMITライセンスの日本語訳を表示します。原文のMITライセンスと第三者ライセンスは配布物に保持しています。

SHA-256:

```text
B1C777F046CD15E6C942B0C339FB3192B9C212EA0F00294AA7F79E60EB1D2B22
```

日本語と空白を含むパスへの導入、配布ファイルの内容照合、CLI起動、ビルド環境診断、上書き更新、アンインストールを検証しています。ビルドツール未導入の別PCでの実機確認は未実施です。

詳しい手順は[インストールガイド](../docs/installation.md)を参照してください。新しいEXEへ更新する際は、ファイル名・サイズ・SHA-256とダウンロードリンクも更新してください。
