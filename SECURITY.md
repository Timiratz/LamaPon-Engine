# Security Policy

## Supported versions

Security fixes are applied to the latest revision of the `main` branch.
Pre-release `0.x` builds may receive breaking fixes when required.

## Reporting a vulnerability

Do not publish exploitable details in a public issue. Use the repository
host's private vulnerability-reporting feature. If private reporting is not
available, contact a maintainer privately before disclosing details.

Include the affected revision, reproduction steps, expected impact, and any
known mitigation. Reports are acknowledged as soon as practical; a disclosure
timeline is agreed after the issue has been reproduced.

Crash dumps can contain paths or game data. Remove sensitive information
before attaching files from a project's `.lamapon/Crashes` directory.
